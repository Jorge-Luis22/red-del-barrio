# Registro de riesgos

Severidad = probabilidad × impacto. Escala: Prob. Baja=1, Media=2, Alta=3 · Impacto Medio=2, Alto=3, Muy alto=4 → severidad 2-12.
Ordenado por severidad descendente. **R1-R29** vienen del contexto (sección 7); **R30-R45** son **nuevos**, hallados al leer el código del PWA en la Fase 1 (marcados ★). Las filas conservan las mitigaciones originales; donde la lectura del código cambia el diagnóstico, se aclara en la columna "Señal temprana".
